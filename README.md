# 울타리치기

데블스플랜 시즌3의 "울타리치기"(슬리더링크) 퍼즐로 반 학생들이 실시간으로 겨루는 웹앱입니다.

- 주소: https://pwoong99.github.io/fence/
- 선생님: 비밀번호로 입장 → 방 번호 4자리가 생김 → 단계·제한 시간 고르고 스타트
- 방 관리: 방을 여러 개 두고 언제든 바꿔 쓰기(지우지 않으면 예전 방 번호도 그대로), 방마다 메모(예: 6학년 3반)
- 학생: 방 번호 + 이름으로 입장 (같은 이름으로 다시 들어오면 이어하기)
- 점수: 맞히면 기본 10점 + 빠른 순서 보너스(1등 +5 … 5등 +1), 단계 배율(연습 ×0.5 · 1~2단계 ×1 · 3~4단계 ×1.5 · 5~6단계 ×2 · 7~8단계 ×3)을 곱함. 오답·시간 초과는 0점. 점수 설정에서 바꿀 수 있음
- 퍼즐: 연습 2단계(3×3) + 본 단계 8단계(4×4~7×7, 숫자 많이/적게), 단계마다 30개, 모두 정답이 하나뿐인지 검증함
- 혼자 연습하기: 학생이 기다리는 동안 3×3·4×4 문제를 풀며 무엇이 틀렸는지 힌트를 받음 (점수 없음)
- 마스코트: 수학 박사 양 (울타리 안에 양을 넣는 이야기)
- Firebase: webapp-hub 프로젝트의 `fence_` 컬렉션 (보안 규칙은 firestore.rules — webapp-hub 전체 규칙)
